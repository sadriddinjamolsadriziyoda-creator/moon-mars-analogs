# Луна и Марс на Земле

**Moon & Mars on Earth** — интерактивный атлас земных локаций, которые можно использовать
как аналоги лунных и марсианских условий. NASA Space Apps Challenge.

Сходство здесь **не заявляется, а считается** по открытым данным и объясняется пользователю:
индекс из шести критериев, формула в коде, у каждого балла — источник.

---

## Что это

30 земных локаций, 18 целей на Луне и Марсе, 6 критериев сходства. Приложение умеет:

- **Атлас** — 3D-глобус Земли, маркеры раскрашены по типу аналога (оранжевый — Марс,
  серый — Луна, фиолетовый — оба), клик открывает карточку с радаром, разбором баллов,
  фото, миссиями и источниками.
- **Обратный поиск** — выбираешь цель на Марсе (Jezero, Valles Marineris, Olympus Mons…),
  получаешь топ-5 земных аналогов с раскрытым разбором баллов.
- **Сравнение** — карта Земли рядом с картой Марса в одной и той же проекции, рамка
  показывает границы аналога.
- **Методика** — формула, допуски, честный список того, чего индекс не делает.

## Запуск

```bash
npm install          # workspaces: root + server + web
npm run dev          # web на :5173, api на :8787
```

MongoDB не обязателен. Без него сервер читает `data/*.json` с диска, а фронтенд при
недоступном API показывает вшитый в бандл каталог и честную плашку «автономный режим».
Это не деградация — это отдельный, протестированный режим работы.

С MongoDB:

```bash
cp .env.example .env    # вписать MONGODB_URI и ADMIN_TOKEN
npm run seed            # идемпотентно по slug
```

npm run typecheck

200 страницей ошибки. Ссылка, которая выглядит рабочей, но ведёт в никуда, хуже отсутствующей.

## Как считается сходство

По критерию `i`, где `f` — нормированный признак места, `t` — признак цели, `Δᵢ` — допуск:

```
sᵢ = clamp(1 − |fᵢ − tᵢ| / Δᵢ, 0, 1)
```

По минералогии — косинус угла между L2-нормированными векторами пяти минералов.

Индекс места:

```
S = 100 · Σ(wᵢ · sᵢ) / Σ wᵢ
```

Критерий, у которого нет измерения, **выпадает и из числителя, и из знаменателя**. Считать его
как 0.5 при сохранении веса значило бы штрафовать место за честное «не измерено».

Формула живёт в `shared/similarity.ts` и импортируется и сервером, и браузером. Радар на карточке
и ответ `/api/similarity` берут одни и те же `sᵢ` — разойтись они не могут.

## Структура

```
shared/        типы и математика — единственный источник истины
data/          sites.json, comparators.json, criteria.json
server/        Express 5 + Mongoose, REST, админка, seed, CI-гейт по источникам
web/           React 18 + TypeScript + Vite, 3D-глобус (globe.gl/three), MapLibre в /compare
scripts/       валидация данных, отчёт по баллам
```

## Честность как требование

- Ни одно место на Земле не воспроизводит Марс или Луну: другой состав атмосферы, другая
  гравитация, другая радиация. Страница `/method` говорит об этом прямо.
- `evidence` не входит в индекс. Уверенность в данных ортогональна похожести, и смешивать их
  в одно число — ложная точность.
- Лунная панель в `/compare` показывает честный урезанный вид: проверенные тайл-серверы Луны
  не отвечали, поэтому вместо пустого экрана — координатная рамка и ссылка на NASA LROC QuickMap.
- Лицензия текстур глобуса не установлена, поэтому страница `/licenses` не заявляет лицензию,
  которую мы не смогли проверить.
